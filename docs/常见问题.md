# AlohaMini 项目问题清单与解决方案

## 一、客户端部署（WSL2 Ubuntu 24.04 Conda）

### 1. pip 源配置

**问题**：pip 下载速度慢，需要配置国内镜像源。

**解决方案**：
```bash
# 添加全局源
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 2. 编译工具链缺失

**问题**：安装 `egl_probe`、`hf-egl-probe`、`evdev` 等包时报错：
```
RuntimeError: cmake not found
make: command not found
gcc: command not found
g++: command not found
```

**解决方案**：
```bash
# 方法一：通过 apt 安装
sudo apt install build-essential cmake

# 方法二：通过 conda 安装（推荐，避免系统环境污染）
conda install cmake make gxx_linux-64 gcc_linux-64
```

---

### 3. Conda 环境损坏 - gdk-pixbuf post-link 脚本失败

**问题**：conda 安装包时 post-link 脚本报错：
```
gdk-pixbuf-query-loaders: command not found
```

**原因**：base 环境缺少交叉编译工具链。

**解决方案**：
```bash
conda install -n base gxx_linux-64 gcc_linux-64
```

---

### 4. cmake 版本过旧

**问题**：apt 最新的不够新，某些包需要较新的 cmake 版本。

**解决方案**：
```bash
# 使用 conda-forge 源安装最新的
conda install cmake -c conda-forge
```

---

### 5. 使用WSL2时，外接的USB设备需要在Windows控制台中共享给WSL2

**原因**：WSL2 环境下无法直接访问 Windows 的 USB 设备。

**解决方案**：
``` bash
usbipd list #查看usb设备清单
usbipd bind --busid 1-1 #把usb设备1-1设为可共享，设置一次即可
usbipd attach --wsl --busid 2-2 #把usb设备2-2共享给wsl2
```

---

### 6. Rerun 可视化 GPU 错误 - R32Float

**问题**：
```
Rerun warning: GPU lacks ability to decode R32Float texture format
```

**原因**：WSL2 环境下 GPU 不支持该纹理格式。

**解决方案**：
```bash
# 更改WGPU_BACKEND
export WGPU_BACKEND=vulkan # 可选值：gl, vulkan, metal, dx12
python examples/alohamini/teleoperate_bi.py --remote_ip 10.1.1.59 --no_leader --arm_profile so-arm-5dof
```

---

### 7. Rerun 文件对话框错误 - zenity 缺失

**问题**：
```
xdg-desktop-portal error
zenity not found
```

**解决方案**：
```bash
sudo apt install zenity
```

### 8. pynput 无法捕获键盘输入（WSL2）

**问题**：在 WSL2 环境下，`pynput.Listener` 无法捕获键盘输入。

**解决方案**：方案：使用 pynput + X11 转发（推荐），需要在监听前打开X窗口

**WSL2中安装依赖**：
``` sh
# 安装 tkinter
sudo apt update
sudo apt install python3-tk
```

**Python中打开窗口（使用Windows11的WSLg）**：
```python
# ============ WSL2 X11 Bridge for pynput ============ #
def create_x11_bridge():
    """创建一个 X11 窗口，pynput 需要窗口激活时才能监听键盘"""
    import tkinter as tk
    root = tk.Tk()
    root.title("WSL2 X11 Bridge - 点击此窗口后使用键盘控制")
    root.geometry("400x100")
    
    label = tk.Label(
        root, 
        text="请点击此窗口激活，然后使用键盘控制机器人\n按 ESC 退出",
        font=("Arial", 12)
    )
    label.pack(expand=True)
    
    def on_close():
        root.quit()
        os._exit(0)
    
    root.protocol("WM_DELETE_WINDOW", on_close)
    print("✅ X11 bridge window created successfully")
    print("   请点击窗口激活后使用键盘控制")
    root.mainloop()

# 启动 X11 bridge 窗口线程
x11_thread = threading.Thread(target=create_x11_bridge, daemon=True)
x11_thread.start()
time.sleep(0.5)
```

### 9. BiSOLeader 无法使用单臂

**问题**：能否只设置一个 leader 臂？

**说明**：`BiSOLeader` 类设计上需要两个 leader 臂（左+右），不支持单臂模式。如需单臂控制，请使用 `SOLeader` 类或直接使用 `--no_leader` 模式。

## 二、服务端部署

### 1. pip 构建临时目录空间不足

**问题**：pip 构建包时会在 `/tmp/pip-build-env-*` 下创建临时环境，多个包同时构建会很快耗尽这 1.9 GB 的内存空间，导致 `No space left on device` 错误。

**解决方案**：让 pip 使用磁盘上的目录作为临时构建目录，而不是内存中的 `/tmp`：

```bash
# 创建磁盘上的临时目录
mkdir -p /root/.pip_tmp
# 设置环境变量，让 pip 使用该目录
export TMPDIR=/root/.pip_tmp
# 然后重新执行安装命令
pip install <你的安装命令>
```

---

### 2. egl_probe CMake 版本兼容性问题

**问题**：`egl_probe` 的 `CMakeLists.txt` 第一行指定的 `cmake_minimum_required` 版本低于 3.5，而系统上安装的 CMake 版本较新，已经移除了对 CMake < 3.5 的兼容性支持。

**解决方案**：

方法一：修改 `egl_probe` 的 `CMakeLists.txt` 文件，将 `cmake_minimum_required` 版本升级到 3.5 或更高。

方法二：在安装前设置环境变量，让 CMake 忽略版本检查：

```bash
export CMAKE_ARGS="-DCMAKE_POLICY_VERSION_MINIMUM=3.5"
pip install -r /root/AlohaMini/lerobot_alohamini/requirements-ubuntu.txt
```

### 3. egl_probe 编译时 cmake 缺失

**问题**：编译 `egl_probe` 时找不到 cmake。

**解决方案**：

```bash
conda install cmake -y
```

**解决方案**：

```bash

sudo apt install -y libsystemd-dev
```
